# Lash Station

Sistema web desenvolvido para gerenciamento e apresentação de serviços de estética (Lash Designer).

## Demonstração
https://lash-station.onrender.com

## Sobre o projeto
O Lash Station é uma aplicação web desenvolvida com foco em estética e serviços de beleza, com interface moderna e integração com inteligência artificial para apoio e automação de respostas.

O projeto foi criado com fins educacionais e para portfólio, demonstrando conhecimentos em backend, frontend e integração com APIs de IA.

## Tecnologias utilizadas
- Python
- Flask
- HTML5
- CSS3
- JavaScript
- Google Gemini API
- Render (Deploy)

## Funcionalidades
- Interface web responsiva
- Backend desenvolvido em Flask
- Integração com inteligência artificial (Google Gemini)
- Deploy em ambiente de produção
- Estrutura preparada para futuras expansões
